# Comprendre v2

Cette surface garde deux lectures complémentaires du même cadrage :

- **Interview** : 6 questions courtes (objectif, contexte, contraintes, parties prenantes, leviers, validation).
- **Restitution** : synthèse visuelle du problème, séparation maîtrisable/subi et chaîne MOE → MOP → TPM.

Le modèle n'est construit qu'au moment où l'utilisateur demande la restitution si le dossier ne contient pas encore de critères et leviers. Les packs déjà structurés réutilisent leurs données existantes. Aucun calcul Forward, Backward ou BORA n'est dupliqué ici.
